# 🃏 Hub de Jogos de Cartas em Python

Este é um projeto desenvolvido em **Python** sincronizado diretamente pelo **VS Code** com o **GitHub**. O objetivo principal é consolidar conceitos de lógica de programação, manipulação de listas (baralhos), estruturas de repetição e condicionais através de jogos clássicos de cartas.

---

## 🚀 Jogos Incluídos

O projeto conta com três jogos clássicos que rodam diretamente no terminal:

*   **Blackjack (21):** Dispute contra a banca! Compre cartas para chegar o mais próximo possível de 21 pontos sem estourar.
*   **Truco:** O clássico jogo de blefe e estratégia brasileiro. Peça Truco, grite Seis e gerencie as manilhas para vencer as rodadas.
*   **Uno:** Fique sem cartas na mão antes dos seus adversários. Use cartas especiais para travar o próximo jogador, mas não se esqueça de gritar "UNO!" quando tiver apenas uma carta.
